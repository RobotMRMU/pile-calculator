全深度换填施工
白砂填筑 · 基底处理 · 碾压组合
🖼️ 工艺附图： Process documentation/1 全深度换填工艺.png
(示意图 — 测量放样·开挖·分层填筑)
📐 施工流程
  1. 测量放样：白天完成开挖线、填筑边线测量并标识
  2. 交通导改：夜间20:30开始设置管制区域
  3. 路基开挖：全深度开挖，基底平整无齿痕
  4. 基底处理：无积水，检测后覆盖土工布(搭接≥45cm)
  5. 白砂填筑：分两层，每层压实厚度30cm
  6. 级配碎石施工：分两层，每层压实厚度20cm
  7. 透层施工：级配碎石顶面洒布透层油
白砂总厚度60 cm
松铺系数1.17 (松铺35cm)
最佳含水率12.1% (±2%)
压实度要求下层≥95% / 上层≥97%
🚜 碾压顺序 (22t/13t单钢轮)
①22t静压1遍 ②洒水 ③22t弱振2遍 ④13t弱振1~2遍 ⑤13t静压收面
速度2km/h · 边角小型压路机/平板夯
✅ 质检允许偏差：高程 ±12mm (白砂顶)

级配碎石施工
双层连铺 · 压实度≥102% · 雨季保护
🖼️ 工艺附图： Process documentation/2 级配碎石施工工艺.png
参数指标
总厚度 / 分层40cm (2×20cm压实)
松铺系数1.35 (松铺27cm)
最佳含水率5.0% (现场4.5%左右)
下层压实度≥98%
上层压实度≥102%
🔁 碾压组合 (22t单钢轮)
第一层
静压1遍 → 弱振1遍 → 强振3遍 → 静压收面
第二层
静压1遍 → 弱振4遍 → 强振2遍 → 静压收面
📏 质检标准
  • 高程偏差：±15mm
  • 平整度：7mm / 3m直尺
  • 厚度：最大值27mm, 90%测点≤21mm, 平均值5mm
🌧️ 雨季施工措施
排水系统全面疏通；运输车辆防雨棚；顶层级配碎石加铺5~8cm保护层并碾压；基底覆盖土工布(搭接≥45cm)

🛡️ 安全防护要求

“先安装、后施工”，桥涵施工区域围挡封闭；道路两侧顺向设置3个锥桶(间距6m)。
